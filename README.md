# Site Auto Reload（Microsoft Edge 拡張）

指定したサイトのタブだけを、指定した間隔で自動リロードする Manifest V3 拡張です。
Edge は Chromium ベースのため、このまま読み込めます（Chrome でも動作します）。

## インストール（Edge・開発者モード）

1. `edge://extensions` を開く
2. 左下の「開発者モード」を ON
3. 「展開して読み込む」→ このフォルダ（auto-reload-plugin）を選択
4. ツールバーに固定すると設定しやすくなります（パズルピースのアイコン → ピン留め）

## ★ Edge で必ずやる設定：スリープタブの除外

Edge は放置したタブを自動でスリープさせ、その間はリロードが止まります。

1. `edge://settings/system` を開く
2. 「これらのサイトをスリープ状態にしない」に、対象サイトのドメインを追加
   - 例: `example.com` / 社内サイトならそのホスト名
3. 監視用に常時表示する場合は「効率モード」も OFF 推奨です

## 使い方
1. ツールバーのアイコンをクリック
2. 「対象サイト」に URL パターンを1行1つで入力
   - `https://example.com/*` （* はワイルドカード）
   - `zabbix` のように短く書けば、URL にその文字を含むタブが対象
3. 間隔（秒）を設定して「保存」
   - Chrome の alarms 仕様のため実用下限は30秒です
4. オプション
   - キャッシュを無視してリロード
   - 今見ている（アクティブな）タブはリロードしない ※ダッシュボード監視用なら OFF 推奨

## 注意
- 対象タブを開いたままにしておく必要があります（タブを閉じるとリロードされません）
- ログインセッションが切れるサイトでは、リロードでログイン画面に戻ることがあります
- フォーム入力中のページはリロードで入力が消えます。「今見ているタブはリロードしない」と併用してください
